# Amazon Project - JavaScript Course

Este repositório contém o desenvolvimento de um clone da interface da Amazon, realizado durante o curso **"JavaScript Tutorial Full Course - Beginner to Pro"** ministrado pelo instrutor **Simon Bao (SuperSimpleDev)**.

O objetivo final deste projeto pode ser visualizado em: [supersimple.dev/projects/amazon](https://supersimple.dev/projects/amazon)

> **Status do Projeto:** Início do desenvolvimento (Configuração de ambiente e arquivos base).

## Sobre o Projeto
Este é um projeto prático focado em dominar o JavaScript Vanilla (puro). O desafio consiste em transformar uma interface estática em uma aplicação funcional, simulando um e-commerce real.

### Créditos e Base do Projeto
Os arquivos iniciais de estrutura e design foram fornecidos pelo curso para garantir que o foco principal seja o aprendizado da lógica de programação.
- **HTML/CSS/Imagens:** Fornecidos por [SuperSimpleDev](https://github.com/SuperSimpleDev/javascript-amazon-project).
- **Lógica JavaScript:** Desenvolvida por mim conforme o progresso das aulas.

## Tecnologias Utilizadas
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3** (Estilização avançada e Flexbox/Grid)

## Roadmap de Desenvolvimento
Acompanhe aqui a evolução das funcionalidades que pretendo implementar:

- [x] Download e organização dos arquivos base.
- [x] Criação da lista de produtos dinamicamente com JavaScript.
- [x] Implementação da lógica do Carrinho de Compras (Adicionar/Remover).
- [x] Cálculo de subtotais e taxas.
- [x] Persistência de dados (Local Storage).
- [x] Gerenciamento de datas de entrega.

## Aprendizados em Foco
Neste projeto, estou focando em aprender e aplicar:
1. **Manipulação do DOM:** Gerar o HTML da página de produtos de forma dinâmica.
2. **Data Structures:** Organizar os produtos e o carrinho usando Objetos e Arrays.
3. **Módulos no JavaScript:** Organizar o código em arquivos separados para melhor manutenção.
